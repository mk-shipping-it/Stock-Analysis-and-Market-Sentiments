**SAMs** is a paper-trading simulator that lets users practice equity-market decisions against live Yahoo Finance quotes without risking capital. It is a vanilla-JavaScript client served from `client/` and an Express + PostgreSQL backend under `server/`, communicating over a small JSON API. Authentication follows the same Google OAuth pattern used elsewhere in this collection of projects (`passport-google-oauth20`), and a JWT issued at sign-in gates every protected route through middleware in `server/middleware/auth.js`.

The backend exposes four route groups. `auth` handles OAuth, session issuance, and account linking. `dashboard` returns the signed-in user's portfolio summary, holdings, and realised/unrealised P&L. `trade` records buy and sell instructions, applies them against the user's notional wallet, and writes a transaction history. `predict` runs a raw-`axios` Yahoo chart forecast and derives a directional signal from regression trend, RSI, and MACD — no external LLM is involved, so there is no fabricated news to expose. Admin operations (user role assignment, wallet adjustments, moderation) live behind a separate `admin` route group protected by `adminRequired`.

The client is intentionally framework-free: pages are static HTML, with state and rendering handled in small modules. It speaks to the API via relative same-origin `/api` (the server serves `client/` statically), and `CORS` `CLIENT_URL` defaults to the same origin. From the project root, `npm run install:all` prepares the workspace, `npm run dev` starts the API with `nodemon` for local iteration, and `npm start` launches it under plain `node`. Configuration is environment-driven through the root `.env`; the server reads `SERVER_PORT`, `CLIENT_URL`, `DATABASE_URL`, `JWT_SECRET`, and the Google OAuth credentials, all of which are documented in `.env.example`.
